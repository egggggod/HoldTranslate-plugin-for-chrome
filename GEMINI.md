# HoldTranslate Workspace Guidelines

## Documentation & README Standard

This project strictly adheres to the [Thinking-Claude](https://github.com/richards199999/Thinking-Claude) style for all documentation and releases:

1. **Bilingual Parity**:
   - `README.md` (English) and `README_zh.md` (简体中文) must remain synchronized in structure, download links, and version tags.
   - Right-aligned language switcher at the top of both files.

2. **Structural Sections**:
   - **Hero**: Title, energetic slogan, reminder blockquote, SVG badges.
   - **Demo**: Compatibility callout, latest release download link, and Light/Dark mode screenshots.
   - **Overview**: 3 core components.
   - **Project Structure**: ASCII directory tree with inline `# comments`.
   - **Extension Features**: Bullet points with high-contrast emojis (`🎯`, `🔄`, `⚡`, `📋`, `🎨`, `🛡️`).
   - **Quick Install Guide**: Manual installation (recommended) with release zip direct link, plus git clone.
   - **Getting Started**: 4-step walkthrough.
   - **Why Use HoldTranslate?**: Key value propositions.
   - **Release Page & Versioning**: Links to Releases page, Semantic Versioning, upgrade instructions.
   - **Contributing & License**: Standard open source footer.

3. **Releases Page**:
   - Title: `Chrome Extension vX.Y.Z`
   - Body: `## What's Changed` + conventional commit bullets with commit/PR links + `**Full Changelog**` link.
   - Concise, brief, and attach packaged `.zip`.
