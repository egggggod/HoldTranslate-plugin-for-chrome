# 以原地原子替换与动态阅读时长稳定字幕

针对自动字幕长句滚动时译文闪现闪退、短句频繁跳变的问题，采用原地原子替换（Zero-blanking）替代原有的超时清空机制。同时引入基于字符阅读速度（CPS）的动态阅读时长（1.2s ~ 5.0s），在保障长句充分可读的前提下，后台静默聚合流式候选译文，到期后原子覆盖；换句与清屏事件立即响应，避免音画脱节。

字幕通过直接按住原文或译文拖动并保存位置，光标保持默认样式。为避免额外控件干扰画面，取消拖动手柄；字幕文字接收鼠标事件，以 6 像素移动阈值区分点击和拖动，普通点击交给播放器，拖动后的点击被拦截。恢复默认位置放在插件设置中，保留双击给播放器处理。
